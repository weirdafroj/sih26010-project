**Smart India Hackathon 2026 | Internal Hackathon - WCEM Nagpur**

**Category:** Hardware | **Theme:** Agriculture, FoodTech & Rural Development

### Problem Summary
Rural land surveys in India still rely on colonial-era chain & tape methods. This leads to boundary disputes due to inheritance, unrecorded transactions, encroachments, mismatched RoR and maps, and no updated mutations.

### Proposed Solution - Team WeirdAfroJ
A tech-driven survey platform combining:
- **Drone Mapping** + RTK/DGPS + CORS for cm-level accuracy
- **GIS Cadastral Mapping** + Satellite Imagery for geo-referenced parcels
- **Mobile Field Verification App** for ground truthing
- **Unified Digital Land System** integrating RoR, Mutation, Registration, Survey Maps, Ownership History with precise geo-coordinates

### Key Features
1. Drone-based aerial survey & orthomosaic generation
2. RTK GPS parcel marking
3. GIS-based cadastral map update & overlay
4. Real-time RoR + Map sync & dispute detection
5. Mobile app for Patwari / field officer verification
6. Transparent land governance dashboard

### Tech Stack
- Hardware: Drone (with RGB/Multispectral), RTK GPS, DGPS
- Software: QGIS / ArcGIS, Python (OpenCV, GDAL), React + Leaflet/Mapbox
- Backend: Node.js / Python FastAPI, PostgreSQL + PostGIS
- Mobile: Flutter / React Native
